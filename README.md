## المصادقة (v1.3.0)
- **إنشاء حساب** ← يُرسل رمز تحقق (6 أرقام) إلى **بريد المستخدم** ← إدخاله يفعّل الحساب ويدخل مباشرة.
- **نسيت كلمة المرور** ← البريد ← رمز إلى البريد ← مطابق = كلمة مرور جديدة / مختلف = رسالة فشل.
- الرمز صالح **10 دقائق**، 5 محاولات، إعادة إرسال بعد 30 ث، يبقى صالحاً بعد الخروج من التطبيق والرجوع.
- إن تعذّر الإرسال (ويب / بلا إعداد SMTP) يُعرض الرمز داخل التطبيق مع زر نسخ.
- بيانات SMTP **ليست في المستودع**؛ تُمرّر وقت البناء (راجع `BUILD_GUIDE.md` §7).

## الأدوار
- **طالب**: يتصفح الدورات، يفتح الدروس، يكتب ملاحظاته، يحل الاختبارات، يحصل على شهادات ويرى إحصاءاته.
- **معلم**: كل ما سبق + إدارة الدورات والدروس والأسئلة ومتابعة الطلاب.
